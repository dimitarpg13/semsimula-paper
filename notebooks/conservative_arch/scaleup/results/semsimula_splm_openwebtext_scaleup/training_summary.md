increased potential-well depth improves energy-landscape sharpness.

## ξ-Channel α Interpretation

The four multi-ξ decay parameters stabilise to a clear multi-scale hierarchy:

| Channel | Final α | Effective EMA horizon | Interpretation |
|---|---|---|---|
| α₀ | ≈ 0 | ~1 token | **collapsed** — pure current-step signal |
| α₁ | 0.4472 | ~1.8 tokens | short-range context |
| α₂ | 0.8004 | ~5 tokens | medium-range context |
| α₃ | 0.9836 | ~61 tokens | long-range context |

This learned separation (≈0, ~2, ~5, ~61 tokens) shows the model spontaneously
discovers a multi-scale temporal integration strategy. Channel 0 collapsing to
zero is consistent with the position-specific mass (`logfreq`) providing a
sufficient per-token local signal, freeing channels 1–3 for progressively
longer-range integration.
