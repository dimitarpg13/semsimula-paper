Reading. Without the reverse channel the registers cannot affect a prediction. In the v1 design the
effect is exactly zero and no gradient reaches the registers. In G3' with the read off, register
content never reaches the tokens. One residue is possible and carries no content: the second LayerNorm
sits inside the reverse-channel block, which runs only if some register is active. If no register is
active at a layer (a strongly perturbed destruction gate can do this), that LayerNorm is skipped. It
acts on an already normalised state, so skipping it only rescales each token's state slightly (by a
factor set by the LayerNorm epsilon and the state's variance): up to 0.02 in a logit with every
register off at both layers. With the trained gate every register is always active.
